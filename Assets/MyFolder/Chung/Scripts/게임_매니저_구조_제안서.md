# VR 멀티 게임 매니저 구조 제안서

## 📋 현재 프로젝트 분석

### 사용 중인 기술 스택
- **네트워크**: Photon PUN 2 (멀티플레이어)
- **백엔드**: PlayFab (인증 및 서비스)
- **VR**: Oculus SDK (Meta Quest)
- **인터랙션**: Oculus Interaction SDK, Unity XR Interaction Toolkit

### 현재 스크립트 분포
- **Yeon 폴더**: 로그인, 게임 시작, 캐릭터 스폰, 아바타 동기화
- **Chung 폴더**: 핸드 매니저, 아이템/리시버 시스템, 그랩 동기화
- **Hoon 폴더**: 포털 시스템 (Adaptive Portal)

### 발견된 문제점
1. ❌ 중앙화된 매니저 시스템 부재
2. ❌ 싱글톤 패턴 미사용으로 인한 참조 문제 가능성
3. ❌ 씬 간 데이터 전달 메커니즘 부재
4. ❌ 게임 상태 관리의 분산화
5. ❌ 네트워크 이벤트 처리의 중복 가능성

## 💡 싱글톤 패턴 구현 제안

### 베이스 싱글톤 클래스
```csharp
// Assets/MyFolder/Shared/Scripts/Utilities/Singleton.cs
public class Singleton<T> : MonoBehaviour where T : MonoBehaviour
{
    private static T _instance;
    private static bool _isApplicationQuitting = false;

    public static T Instance
    {
        get
        {
            if (_isApplicationQuitting)
            {
                return null;
            }

            if (_instance == null)
            {
                _instance = FindObjectOfType<T>();

                if (_instance == null)
                {
                    GameObject singleton = new GameObject(typeof(T).Name);
                    _instance = singleton.AddComponent<T>();
                    DontDestroyOnLoad(singleton);
                }
            }

            return _instance;
        }
    }

    protected virtual void Awake()
    {
        if (_instance == null)
        {
            _instance = this as T;
            DontDestroyOnLoad(gameObject);
        }
        else if (_instance != this)
        {
            Destroy(gameObject);
        }
    }

    protected virtual void OnApplicationQuit()
    {
        _isApplicationQuitting = true;
    }
}
```

### 매니저 사용 예시
```csharp
public class NetworkManager : Singleton<NetworkManager>, MonoBehaviourPunCallbacks
{
    // NetworkManager.Instance로 접근 가능
}
```

## ⚠️ 주의사항

### 1. Photon 콜백 처리
- `MonoBehaviourPunCallbacks`를 상속받는 매니저는 하나만 존재해야 함
- **해결책**: NetworkManager만 `MonoBehaviourPunCallbacks` 상속, 다른 매니저는 이벤트로 통신

### 2. 씬 전환 시 매니저 유지
- Core Managers는 `DontDestroyOnLoad` 적용
- Feature Managers는 씬별로 필요시 생성/제거

### 3. 초기화 순서
- NetworkManager → GameManager → VRManager → 기타 순서로 초기화
- `Awake()`에서 다른 매니저 참조 시 주의

### 4. 멀티플레이어 동기화
- Master Client만 실행해야 하는 로직 명확히 구분
- RPC 호출 시 네트워크 상태 확인
